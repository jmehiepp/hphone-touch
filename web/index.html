Lua API bản đầu
print(...), log(...), sleep(seconds), tap(x, y), key('home'), screenshot() → chuỗi PNG, ocr() → bảng kết quả.
Tọa độ chạm theo pixel ảnh gốc, hướng dọc. OCR trả hộp chuẩn hóa 0–1, gốc trái dưới. Phím: home, power, volumeUp, volumeDown. Script có quyền của tài khoản mobile; chỉ chạy mã bạn tin cậy.
API native chưa được xác nhận trên mọi máy. Bản này chưa có tìm ảnh, swipe, vòng lặp đa thiết bị, cookie, keychain hoặc sao lưu/khôi phục app.
